# AI Small Business Assistant for Side Hustlers

## About the Project
An AI-powered assistant designed to help small business owners and side hustlers with everyday business tasks.

## Features
- AI-powered chat assistant
- Product price checking
- Simple and user-friendly Streamlit interface
- SQLite database integration

## Technologies Used
- Python
- Streamlit
- Ollama
- Qwen2.5:3B
- SQLite

## How to Run Locally
1. Clone this repository.
2. Install the required packages using `pip install -r requirements.txt`.
3. Ensure Ollama is installed and the required model is available.
4. Run the application using `streamlit run app.py`.
